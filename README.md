# Telegram-бот на Kiva

Бот-заглушка на языке [Kiva](https://github.com/Gudhein3/kivac): на команду `/start` отвечает «привет». Обновления приходят через long polling (`getUpdates`), HTTP делает libcurl, JSON разбирает jansson.

Kiva собирается под x86-64 Linux, поэтому бот работает только на нём.

## Что понадобится

| Что | Arch / EndeavourOS | Debian / Ubuntu |
| --- | --- | --- |
| компилятор C, make, git | `base-devel git` | `build-essential git` |
| ассемблер | `nasm` | `nasm` |
| библиотеки | `curl jansson` | `libcurl4-openssl-dev libjansson-dev` |

Для `make test` ещё нужен [uv](https://docs.astral.sh/uv/).

## Сборка

```sh
make
```

Первый запуск сам скачивает компилятор Kiva в `.kiva/` (закреплён конкретный коммит, права root не нужны) и собирает его. Бот получается в `build/tgbot`.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Подготовьте настройки:

   ```sh
   cp .env.example .env
   ```

   и впишите токен в `BOT_TOKEN`.
3. Запустите:

   ```sh
   make run
   ```

Напишите боту `/start` — он ответит «привет». Остановить бота можно через Ctrl+C.

Если Telegram напрямую недоступен, добавьте в `.env` прокси, например `all_proxy=socks5h://127.0.0.1:1080` — libcurl подхватывает его сам. Адрес API меняется переменной `TELEGRAM_API_URL` (например, для локального [Bot API сервера](https://core.telegram.org/bots/api#using-a-local-bot-api-server)).

## Проверка

```sh
make test
```

Тест запускает бота против поддельного Bot API и проверяет ответы на `/start`, подтверждение обновлений через `offset` и поведение при неверном или отсутствующем токене. Настоящий токен не нужен.

## Устройство

- `src/bot.k` — весь бот.
- `scripts/setup-kiva.sh` — сборка компилятора Kiva.
- `tests/e2e.py` — сквозной тест.
- `Makefile` — цели `all`, `run`, `test`, `clean`, `distclean` (последняя удаляет и компилятор).

Особенности Kiva, которые важно помнить при доработке бота:

- Типов нет: любое значение — 64-битное слово, константы libcurl записаны числами.
- Нет `&&` и `||`: условия собираются через `&` и `|` над сравнениями в скобках.
- Сравнения беззнаковые, `int`-результаты C-функций стоит маскировать `& 0xFFFFFFFF`.
- Модулей нет, исходник один; у функции не больше шести параметров.
